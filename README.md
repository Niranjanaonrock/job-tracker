# Job Tracker

A simple **job application tracker** built with **vanilla JavaScript, HTML, and CSS**.  
Track your job applications, interviews, and follow-up dates with a responsive, interactive web app.

---

## 🔹 Live Demo

Try it live here: https://niranjanaonrock.github.io/job-tracker/

---

## 🔹 Features

- **Add jobs** with company name, status (Applied / Interview / Rejected), and follow-up date  
- **Inline editing**: update job details without deleting  
- **Delete jobs**  
- **Prevent duplicates** (same company + status)  
- **Persistent storage** using browser `localStorage`  
- **Color coding** for job status  
- **Overdue follow-up alert** (red border for past dates)  
- **Filter by status**  
- **Sort by company name or follow-up date**  
- **Mobile responsive design**  

---

## 🔹 Technologies Used

- HTML5  
- CSS3 (including responsive design)  
- Vanilla JavaScript (DOM manipulation, event handling, localStorage)

---

## 🔹 Usage

1. Open the live demo or clone the repository  
2. Enter company name, select status, optionally choose follow-up date  
3. Click **Add Job**  
4. Edit jobs inline using the ✏️ button  
5. Delete jobs using the ❌ button  
6. Use filters and sorting to manage your job list
